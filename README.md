# Illustrator-Live Link

Illustrator 2022–2026 与 Blender 4.0 / 4.5 的实时纹理链接插件（Windows）。

[下载最新版](https://github.com/Linbainuo/Illustrator-Live-Link/releases/latest)

## 中文安装

1. 下载并解压 `Illustrator-Live-Link-1.0.0-Windows.zip`。
2. 完全退出 Illustrator，运行 Illustrator 文件夹内的安装脚本。
3. 安装器会保持窗口打开，并明确显示安装位置与成功/失败结果。
4. 在 Blender 的 `Preferences > Add-ons > Install from Disk` 中安装 Blender 文件夹内的 ZIP。
5. 重启 Illustrator 和 Blender。

Illustrator 与 Blender 两端插件都需要安装。

如果 Illustrator 自动安装失败，把 Illustrator 安装包内整个
`Illustrator-Live Link` 文件夹复制到 Illustrator 的 `Plug-ins` 文件夹。
`.aip` 与 Renderer 必须保留在同一文件夹中。

## English Installation

1. Download and extract `Illustrator-Live-Link-1.0.0-Windows.zip`.
2. Quit Illustrator, then run the installer inside the Illustrator folder.
3. The installer stays open and clearly reports its target and success or failure.
4. In Blender, open `Preferences > Add-ons > Install from Disk` and select the ZIP inside the Blender folder.
5. Restart Illustrator and Blender.

Both the Illustrator and Blender plug-ins are required.

If automatic Illustrator installation fails, copy the complete
`Illustrator-Live Link` folder from the package into Illustrator's `Plug-ins`
folder. Keep the `.aip` and Renderer together in that folder.

Tested with Illustrator 2022/2026 and Blender 4.0.2/4.5.8.
