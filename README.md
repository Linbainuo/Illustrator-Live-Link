# Illustrator-Live Link

Illustrator 2026 与 Blender 4.0 / 4.5 的实时纹理链接插件（Windows）。

[下载最新版](https://github.com/Linbainuo/Illustrator-Live-Link/releases/latest)

## 中文安装

1. 下载并解压 `Illustrator-Live-Link-1.0.0-Windows.zip`。
2. 完全退出 Illustrator，运行 Illustrator 文件夹内的安装脚本。
3. 在 Blender 的 `Preferences > Add-ons > Install from Disk` 中安装 Blender 文件夹内的 ZIP。
4. 重启 Illustrator 和 Blender。

Illustrator 与 Blender 两端插件都需要安装。

## English Installation

1. Download and extract `Illustrator-Live-Link-1.0.0-Windows.zip`.
2. Quit Illustrator, then run the installer inside the Illustrator folder.
3. In Blender, open `Preferences > Add-ons > Install from Disk` and select the ZIP inside the Blender folder.
4. Restart Illustrator and Blender.

Both the Illustrator and Blender plug-ins are required.
